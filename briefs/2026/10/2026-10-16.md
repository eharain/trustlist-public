## Security advisories

### [Chrome 155 update fixes ten security bugs, one rated critical](https://trustlist.uk/security-advisories/chrome-155-0-8059-84-fixes-ten-security-bugs-critical-prerender-use-after-free-cve-2026-110922)

Version 155.0.8059.84/.85 patches a critical use-after-free in Prerender and six high-severity bugs, four of them in the V8 engine. Hong Kong's CERT warns of remote code execution.

### [Nextcloud's built-in Collabora server flaw was exploited before disclosure](https://trustlist.uk/security-advisories/nextcloud-built-in-code-server-cve-2026-110447-exploited-before-disclosure-upgrade-26-4-303)

CVE-2026-110447 lets an attacker run commands on a Nextcloud server with no login while the built-in CODE server is down. A fix shipped on 11 September; the CVE followed on 14 October.

### [Cisco Meraki hardening release covers seven flaw classes, top score 9.6](https://trustlist.uk/security-advisories/cisco-meraki-hardening-release-seven-cves-cvss-9-6-mx-mr-ms-mg-mv-fixed-builds)

Every Meraki MX, MR, MS, MG and MV device and Campus Gateway is affected whatever its settings. Some fixed builds arrive only in late October or mid-November, and there are no workarounds.

### [Linux kernel flaw lets a guest VM read and crash its host](https://trustlist.uk/security-advisories/linux-kernel-pwnescape-cve-2026-99999-guest-reads-host-memory-fixed-6-12-113-6-6-159)

CVE-2026-99999, nicknamed PwnEscape, scores 9.3 and sits in the IPv4 checksum code every host kernel runs. Fixed stable kernels range from 5.10.272 to 7.2.11.

### [BeyondTrust Remote Support flaw exploited as a zero-day since August](https://trustlist.uk/security-advisories/beyondtrust-remote-support-cve-2026-102764-exploited-as-zero-day-patch-bt26-05-rs)

CVE-2026-102764 scores 9.3 and affects Remote Support 26.2.3 and earlier. Mandiant traced exploitation to late August; versions before 24.3.1 get no patch and must be upgraded.

### [Windows 11 October update can stop Smart App Control turning back on](https://trustlist.uk/security-advisories/windows-11-kb5127648-smart-app-control-cannot-be-turned-back-on-workarounds)

KB5127648 for versions 24H2, 25H2 and 26H2 can grey out the switch once the feature is off. Microsoft gives a registry fix and two Group Policy packages until a permanent fix ships.

### [Microsoft Edge will switch off built-in XSLT from mid-December](https://trustlist.uk/news/microsoft-edge-turns-off-browser-native-xslt-edge-159-mid-december-2026-policy-ends-edge-176)

Edge 159 disables the XSLTProcessor API and XSL stylesheet instructions by default. A temporary XSLTEnabled policy buys time until Edge 176 in summer 2027.

### [Leap seconds end as UTC becomes continuous on 20 May 2027](https://trustlist.uk/news/leap-seconds-end-continuous-utc-from-20-may-2027-cgpm-resolution-5)

The 28th General Conference on Weights and Measures brought the change forward from 2035, citing a 30% chance of a first negative leap second by then and the cost of preparing for one.
