## Security advisories

### [Oracle patches a CVSS 9.1 Java TLS flaw in an out-of-cycle alert](https://trustlist.uk/security-advisories/oracle-java-se-security-alert-cve-2026-91403-jsse-cvss-9-1-patch-again-after-october-cpu)

CVE-2026-91403 in JSSE can be exploited over the network with no login. Every listed build is affected, including 25.0.5 and 21.0.13, so Java estates need to patch again.

### [Splunk Enterprise and SOAR fix critical flaws scoring up to 9.9](https://trustlist.uk/security-advisories/splunk-enterprise-10-4-4-and-soar-8-7-0-fix-critical-flaws-cvss-9-9-postgres-sidecar-key)

Enterprise 10.4.4, 10.2.8, 10.0.11 and 9.4.16 and SOAR 8.7.0 close internally found flaws, an unauthenticated crash of Splunk Web and a sidecar password any low-privileged user could derive.

### [Laravel fixes an API token bypass that hands over any account](https://trustlist.uk/security-advisories/laravel-cve-2026-114509-tokenguard-auth-bypass-cvss-9-2-upgrade-13-29-0-12-68-0)

CVE-2026-114509 lets an attacker with no token log in as an existing user on apps using TokenGuard with MySQL or MariaDB. Upgrade to 13.29.0 or 12.68.0; a proof of concept is public.

### [Microsoft ties ConnectWise breach to Storm-0940 and an AI attack framework](https://trustlist.uk/security-advisories/microsoft-ties-connectwise-cloud-backup-compromise-to-storm-0940-and-artex-agentic-ai-framework)

Microsoft says a China-aligned group used ARTEX, an open-source multi-agent pen-testing tool, to reach privileged cloud access in under three hours in some cases, and lists the Entra checks every affected tenant should run.

### [PAN-OS and Panorama are hit by the PHP flaws, with no fix date yet](https://trustlist.uk/security-advisories/palo-alto-pan-os-and-panorama-affected-by-php-flaws-cve-2026-109618-no-fix-yet-restrict-management)

Palo Alto lists every supported PAN-OS line and Panorama as affected by CVE-2026-109618 and CVE-2026-109619 through the management interface. Threat Prevention signatures and access limits are the stopgaps.

### [QPACK flaws let one connection exhaust memory on HTTP/3 servers](https://trustlist.uk/security-advisories/qpack-header-accordion-flaws-exhaust-memory-on-http-3-servers-quic-go-quiche-lsquic-bun)

FoxIO found seven of ten HTTP/3 stacks open to header amplification. quic-go, Cloudflare quiche, lsquic and Wireshark are fixed; Bun, the h3 crate and aioquic are not, and a proof of concept is public.

### [Apache Camel 4.22.1 users need 4.22.2 for seven more flaws](https://trustlist.uk/security-advisories/apache-camel-seven-more-cves-fixed-in-4-22-2-4-22-1-users-still-exposed)

A week after 38 advisories, Camel published seven more on 22 October, led by a High-rated XXE in camel-saxon. On the 4.22 LTS line only 4.22.2 fixes them; 4.18.5 and 4.23.0 already do.

### [AWS fixes an agent SDK flaw that mixed up callers' conversations](https://trustlist.uk/security-advisories/aws-fixes-strands-agents-a2a-session-leak-cve-2026-115419-and-sam-cli-terraform-hook-injection)

Four AWS bulletins on 22 October: Strands Agents A2A servers leaked conversation history between callers, SAM CLI's Terraform hook allowed command injection, Athena exposed query text, and aws-c-mqtt could crash clients.
