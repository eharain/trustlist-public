## Security advisories

### [MongoDB fixes pre-auth replica set flaw CVE-2026-118383 (CVSS 9.5)](https://trustlist.uk/security-advisories/mongodb-cve-2026-118383-pre-auth-use-after-free-replica-sets-fixed-9-0-7-8-0-37)

A request needing no login can crash a newly elected primary or, in some conditions, run code. Fixed in 9.0.7, 8.3.16, 8.0.37, 7.0.48, 6.0.30, 5.0.35 and 4.4.32; Atlas upgrades during maintenance.

### [NoisyTCP: 11-year-old Linux flaw lets attackers crash servers](https://trustlist.uk/security-advisories/noisytcp-linux-kernel-cve-2026-99288-remote-crash-of-plain-tcp-listeners-fix-and-mitigations)

CVE-2026-99288 needs no login and no special configuration, only a TCP port an attacker can reach. The fix went into the kernel on 3 November; two stopgaps exist for hosts that cannot take it yet.

### [Gitea 28.4.0 closes a hook overwrite and a password-hash leak](https://trustlist.uk/security-advisories/gitea-28-4-0-fixes-auto-init-command-execution-cve-2026-125423-and-password-hash-leak-cve-2026-123006)

The fourth maintenance release of the 28 series follows the 20 advisories fixed in 28.3.0 two weeks earlier. One of its flaws has exposed repository owners’ password hashes to any signed-in user since 28.0.0.
