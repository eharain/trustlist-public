<p class="related"><span class="label">Related on TrustList</span>: <a href="https://trustlist.uk/best/countries/taiwan">Top B2B companies in Taiwan</a></p>

### [Gitea 28.3.0 fixes 20 flaws, from account takeover to leaked secrets](https://trustlist.uk/security-advisories/gitea-28-3-0-fixes-20-advisories-oauth-account-takeover-fork-workflow-secrets-public-only-token-bypasses)

Seven are rated high, including an account takeover through OAuth2 auto-linking and fork workflows that receive repository secrets. Every release up to 28.2.0 is affected; there is no backport line.

### [Juniper fixes two critical root flaws in Session Smart Router](https://trustlist.uk/security-advisories/juniper-session-smart-router-conductor-critical-flaws-jsa112183)

Both are rated 9.8 and need no login: one runs commands as root on Session Smart Conductor, the other hands admin rights on routers not yet onboarded. Fixed in 7.0.5, 7.1.7 and 7.2.3; Juniper says no workaround exists.

### [Progress discloses critical WS\_FTP Server flaws fixed weeks ago](https://trustlist.uk/security-advisories/progress-ws-ftp-server-critical-flaws-fixed-2025-0-4-2024-0-7)

CVE-2026-84295, rated 10.0, lets an attacker with no login read WS\_FTP admin credentials on Windows. Five more rated 9.0 to 9.9 are fixed in 2025.0.4 and 2024.0.7, released on 1 October and published as CVEs on 29 October.

### [JetBrains IDEs still trusted compromised eMudhra certificates](https://trustlist.uk/security-advisories/jetbrains-ides-toolbox-emudhra-compromised-certificates-cve-2026-118697)

The IDEs ship their own Java runtime and trust store, so an operating system update does not remove the eight compromised intermediates. Fixes run from 2026.2.4 and Toolbox 3.9.1; 2025.1 and older get none.

### [Traefik 3.7.17 stops NTLM headers exhausting proxy memory](https://trustlist.uk/security-advisories/traefik-3-7-17-2-11-61-fix-ntlm-negotiate-memory-exhaustion)

A client with no credentials can tie up memory, file descriptors and backend connections on Traefik 3.7.14 to 3.7.16 and 2.11.58 to 2.11.60, whether or not NTLM is used. It is the latest of more than a dozen fixes since 6 October.

### [Langflow 1.13.0 fixes two unauthenticated 9.8 flaws in every 1.x release](https://trustlist.uk/security-advisories/langflow-1-13-0-fixes-critical-unauthenticated-flaws-cve-2026-93680-110186)

IBM's records cover Langflow OSS 1.0.0 to 1.12.8: an authentication bypass and code execution, both 9.8 with no login needed. Version 1.12.8, released hours before the fix, is still affected.
