## Security advisories

### [Cisco reissues fix for exploited Secure Email Gateway flaw CVE-2026-76461](https://trustlist.uk/security-advisories/cisco-secure-email-gateway-cve-2026-76461-sql-injection-root-exploited-since-september-fix-reissued-31-october)

A crafted email gives an unauthenticated attacker root through SQL injection in AsyncOS (CVSS 9.8). Cisco has known of attacks since September and replaced the 15.5.5-014 fix on 31 October after exploit code appeared online.

### [Elastic 8.19.24, 9.4.9 and 9.5.6 fix 21 flaws, 12 rated high](https://trustlist.uk/security-advisories/elastic-8-19-24-9-4-9-9-5-6-fix-21-flaws-brotli-code-execution-and-emudhra-trust-stores-esa-2026-200-to-238)

Ten of the high-rated advisories trace to two bundled dependencies: a Brotli decoder bug in Node.js and the compromised eMudhra roots in Java, Node.js and Docker image trust stores. Elastic did not reproduce code execution in Kibana.

### [XSA-523: two grant copy flaws let a Xen guest read and write Dom0 memory](https://trustlist.uk/security-advisories/xen-xsa-523-grant-copy-flaws-cve-2026-102703-and-102704-let-a-guest-read-and-write-dom0-memory-no-mitigation)

Every Xen from 4.6 is affected and the advisory knows of no mitigation, only patches, which it lists for releases back to 4.17. Two more advisories, XSA-529 and XSA-530, are embargoed until 10 November.

### [Cisco fixes UCS Central flaw that lets a logged-in user run commands](https://trustlist.uk/security-advisories/cisco-ucs-central-cve-2026-76506-authenticated-command-execution-fixed-2-1-2c)

CVE-2026-76506 (CVSS 7.6) lets any user with valid credentials run commands, write files and read data through the web interface. Release 2.1(2c) fixes it; 2.0 and earlier must migrate, and there is no workaround.

The image handler in the WordPress and Joomla builder lets anyone write a PHP file to the uploads folder. YOOtheme fixed it in 5.0.53 on 21 October; Unit 42 saw webshells two days later and JPCERT/CC flagged it on 5 November.

CVE-2026-109518 abuses APT's handling of hard links when it follows redirects and retries downloads, which is on by default from Debian 12 and Ubuntu 22.04. Fixed packages shipped on 4 November.

### [FreeSWITCH flaw lets one SIP MESSAGE run server commands](https://trustlist.uk/security-advisories/freeswitch-cve-2026-116779-sip-message-api-command-execution-exploited-fixed-1-11-3)

CVE-2026-116779, rated 9.8, lets a SIP MESSAGE pick FreeSWITCH's api chat route and run any API command. The project says it has been exploited. Version 1.11.3 closes the route by default; enable-chat=false is the workaround.

### [OpenSSH 10.6p2 closes a password bypass on musl Linux without PAM](https://trustlist.uk/security-advisories/openssh-10-6p2-sshd-password-authentication-bypass-musl-linux-without-pam-alpine)

Linux systems built on musl libc with PAM disabled, Alpine among them, can have sshd password authentication bypassed. The maintainers say set PasswordAuthentication=no or turn SSH off at once, then upgrade to 10.6p2.

### [zlib 1.4 fixes a dozen memory bugs and changes its build](https://trustlist.uk/security-advisories/zlib-1-4-fixes-gzwrite-overflow-cve-2026-85091-inflategetdictionary-and-minizip-flaws-breaking-build-changes)

The compression library's first release since 1.3.2 fixes CVE-2026-85091 in non-blocking gzwrite(), an 8 MB overwrite in inflateGetDictionary() and minizip path flaws. It also renames MSVC libraries and moves the CMake floor to 3.15.
