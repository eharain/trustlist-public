# Database engine rankings

TrustList ranks database engines in five groups. Each engine's listing is built from its own pages:
its maker, website, licence, deployment options, first release, latest version and published pricing.
Popularity ranks, third-party benchmarks and market share estimates are not used.

| Group | Ranking |
|---|---|
| Relational (SQL) engines | [Top relational (SQL) database engines](https://trustlist.uk/best/rdbms-software/sql) |
| NoSQL engines | [Top NoSQL database engines](https://trustlist.uk/best/nosql-databases-software/nosql) |
| Analytical databases and data warehouses | [Top analytical databases and data warehouses](https://trustlist.uk/best/data-warehouse-software/data-warehousing) |
| Vector databases | [Top vector databases](https://trustlist.uk/best/vector-database-software/vector-database) |
| Time-series databases | [Top time-series databases](https://trustlist.uk/best/time-series-database-software/time-series) |

All five are part of the [Q4 2026 edition](https://trustlist.uk/best/editions/2026-Q4) and follow the
[TrustList Score method](how-trustlist-ranks.md).

## Maintainers

If you maintain one of these engines and something on its listing is wrong or out of date (a version,
a licence, a deployment option), open an issue in this repository or use the correction link on the
listing page. Corrections are checked against the engine's own pages and published with the date.
