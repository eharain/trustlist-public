# TrustList resources

Pointers to TrustList's public rankings and data, for developers, researchers and anyone comparing
software and service providers.

- [How TrustList ranks](how-trustlist-ranks.md): the score, the evidence it uses, and the quarterly
  editions.
- [Database engine rankings](database-engines.md): relational, NoSQL, analytical, vector and
  time-series engines.
- [Software rankings by feature](software-rankings.md): tools for one job compared across categories.
- [B2B companies by country](companies-by-country.md): firms ranked by country and category.

Elsewhere on TrustList:

- [Ranking editions](https://trustlist.uk/best/editions): every quarterly edition and what changed.
- [Articles](https://trustlist.uk/articles): news, guides and research.
- [Companies raising](https://trustlist.uk/funding): live funding rounds.
- [Awards](https://trustlist.uk/awards): annual recognition decided by verified reviews and a jury.
- [Get vetted](https://trustlist.uk/vetting): what TrustList checks, for businesses that want it.
- [Developer API](https://trustlist.uk/developers): the API and its documentation.

Something wrong or missing? Open an issue in this repository.
