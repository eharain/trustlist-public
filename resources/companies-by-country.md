# B2B companies by country

TrustList ranks B2B firms in each country, category by category: software makers, IT service
providers, agencies, accounting firms, recruiters and more. A firm counts for a country when its own
pages give an address there. The full list is at
[trustlist.uk/best/countries](https://trustlist.uk/best/countries).

- [United Kingdom](https://trustlist.uk/best/countries/united-kingdom)
- [United States](https://trustlist.uk/best/countries/united-states-of-america)
- [Canada](https://trustlist.uk/best/countries/canada)
- [Australia](https://trustlist.uk/best/countries/australia)
- [Germany](https://trustlist.uk/best/countries/germany)
- [India](https://trustlist.uk/best/countries/india)
- [Pakistan](https://trustlist.uk/best/countries/pakistan)
- [United Arab Emirates](https://trustlist.uk/best/countries/united-arab-emirates)

Each country page links to that country's rankings by category. How the order is decided:
[How TrustList ranks](how-trustlist-ranks.md).
